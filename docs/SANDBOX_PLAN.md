## 一、设计理念

```
个人线（太阁立志传式）：
  行事正义或邪恶 → 影响 NPC 态度与势力关系
  自由修炼突破 → 修为与宗门身份解耦，各自独立推进
  行走江湖 → 探索各门派城市，触发随机事件

势力线（信长之野望式）：
  从外门弟子 → 内门 → 真传 → 长老 → 掌门（贡献值驱动，平行于剧情晋升）
  势力倾向（正道/中立/邪道/混乱）→ 驱动 NPC 和势力间外交行为
  NPC 个性受势力文化影响 → 友好或敌对行为非纯随机
```

两条线互相交织但独立推进。沙盒模式下，玩家可以不推主线剧情，通过贡献值 + 试炼晋升宗门身份。

## 二、与现有系统的关系

### 2.1 修为与宗门身份解耦（已实装）

> 这是 0507 突破机制重构的核心成果，沙盒模式直接继承：

| 维度 | 主线模式 | 沙盒模式 |
|------|---------|---------|
| 修为突破 | 剧情解锁 `realmBreakUnlocked` → 玩家点击突破 | 同上，或通过突破丹（未来）替代剧情解锁 |
| 宗门身份 | 剧情设置 `discipleRank`（ch2_xiasha→inner, ch3_zhenchuan→true） | 贡献值 + 晋升试炼 → 平行晋升路径 |
| 两者关系 | 完全解耦，互不影响 | 同左 |

### 2.2 沙盒模式不破坏现有剧情

- 现有 10 个地点（`worldMap.ts`）**全部保留**，沙盒模式在此基础上扩展
- 现有剧情节点（ch1~ch3）**不受影响**，沙盒系统作为独立模块叠加
- 贡献值是**新增货币**，不替代现有金币系统
- `discipleRank` 字段共用，剧情晋升和沙盒晋升写入同一个字段

## P0-2: 宗门晋升系统（沙盒路径）✅ 已完成

### 目标
提供一条**独立于主线剧情**的宗门晋升路径。玩家可以通过积累贡献值 + 完成晋升试炼来提升 `discipleRank`，无需等待剧情推进。

### 核心设计

```
晋升条件（沙盒路径）：
  外门 → 内门：贡献值 ≥ 200 + 完成晋升试炼（剿匪/比武）
  内门 → 真传：贡献值 ≥ 500 + 完成晋升试炼（试剑会）
  真传 → 长老：贡献值 ≥ 1000 + 完成晋升试炼（教导任务）
```

**关键：不使用 `minLevel` 作为晋升条件**。修为与宗门身份解耦——一个炼气期的天才也可以通过贡献值和试炼成为内门弟子（虽然战斗试炼可能很难打过）。

### 与剧情晋升的关系

| 晋升方式 | 触发条件 | 说明 |
|----------|---------|------|
| 剧情晋升 | 推进主线到特定节点 | ch2_xiasha→inner, ch3_zhenchuan→true |
| 沙盒晋升 | 贡献值达标 + 完成试炼 | 不推主线也能晋升 |

两种方式写入同一个 `discipleRank` 字段。如果玩家已通过剧情晋升到内门，沙盒晋升条件自动切换到下一级（内门→真传）。

## P1-2: 势力倾向系统 + NPC 行为驱动 ✅ 已完成

### 目标
参考信长之野望的势力文化/倾向，让 NPC 和势力的行为不再是纯随机，而是由其"性格"驱动。正道门派倾向于友好合作，邪道门派倾向于冲突掠夺。

### 设计原则

1. **基于现有 `SectId`**：当前有 6 个势力（`wudang | emei | shaolin | beggar | huashan | demon`），势力倾向系统首先覆盖这 6 个
2. **NPC 行为受势力倾向影响**：同一势力下的 NPC 共享文化标签，行为偏向一致
3. **势力间外交由倾向 + 文化相似度驱动**：非纯随机
4. **玩家行为影响势力关系**：玩家介入势力冲突可改变走向

### 势力倾向定义（基于现有 SectId）

| 势力 | SectId | 倾向 | 文化标签 | 说明 |
|------|--------|------|----------|------|
| 武当派 | `wudang` | `righteous` | taoist, sword, mountain, inner-peace | 道教正宗，以柔克刚 |
| 少林寺 | `shaolin` | `righteous` | buddhist, fist, temple, discipline | 禅武合一，武林泰山 |
| 峨眉派 | `emei` | `righteous` | buddhist, sword, mountain, female | 佛门女修，剑法精妙 |
| 丐帮 | `beggar` | `righteous` | beggar, palm, street, loyalty | 天下第一大帮，忠义为本 |
| 华山派 | `huashan` | `neutral` | sword, mountain, rivalry | 剑气二宗之争，独善其身 |
| 魔教 | `demon` | `chaotic` | moon, shadow, forbidden, power | 黑月教等魔道势力的统称 |

### 冲突逻辑（非纯随机）

```
每 N 回合执行一次势力外交 tick：

1. 计算两两势力间的基础友好度修正：
   - 倾向匹配（ALIGNMENT_AFFINITY 表）
   - 文化相似度（共同标签数 × 10）

2. 根据当前友好度决定事件概率：
   友好度 > 60  → 70%友好事件 / 20%无事 / 10%摩擦
   友好度 30-60 → 40%友好 / 40%无事 / 20%冲突
   友好度 < 30  → 15%友好 / 35%无事 / 50%冲突

3. 友好事件示例：
   - 武当&少林：联合论道（双方声望+）
   - 峨眉&武当：弟子交流（双方关系+）

4. 冲突事件示例：
   - 武当&魔教：边境冲突（小规模战斗）
   - 华山&魔教：弟子被暗算（关系恶化）

5. 玩家可介入事件，影响势力关系走向
```

### 偷师机制设计

```
进入其他宗门地点 → 可选择「偷师」行动：

1. 成功率 = 基础成功率 + 玩家等级加成 - 目标门派警戒度

   - 标记为「偷学」，威力打 8 折

   - 使用偷学武功被原门派 NPC 看到 → 立即被发现

5. 连续偷师同一门派 → 警戒度累积上升
```

## P3: 世界演算引擎 — 三国志13 势力线 ✅ 已完成 (2026-05-09)

### 目标
借鉴三国志13的个人-势力线，让江湖拥有一个"活"的世界状态。每个门派保持独立的资源（资金、弟子、地盘、声望、稳定、武力），资源随时间演化，世界事件随机触发，玩家的每次行动都在书写自己的"个人日志"。

### 架构设计

```
┌────────────────────────────────────────────────┐
│                WorldState (世界状态)              │
│  factionResources: { 武当:{金/人/地/望/稳/武} … } │
│  worldEvents: [{事件ID, 回合, 时间}…]             │
│  turn: N                    ← 每3回合演化一次     │
├────────────────────────────────────────────────┤
│               Chronicle (个人日志)                │
│  entries: [{ID, 分类, 标题, 描述, 地点, 时间}…]   │
├────────────────────────────────────────────────┤
│          doDailyTask() → tickWorldState()        │
│            → addChronicleEntry()                  │
│            → contributeToFaction()                │
└────────────────────────────────────────────────┘
```

### 核心功能一览

| 功能 | 说明 | 实现 |
|------|------|------|
| 势力资源 | 6门派各有 gold/disciples/territory/prestige/stability/militaryPower | `initWorldState()` |
| 资源演化 | 每3回合各资源 ±2 波动，外交关系影响稳定度 | `tickWorldState()` |
| 世界事件 | 10种江湖事件（武林大会、匪患、商路、疫病、魔教渗透等），10%触发概率 | `WORLD_EVENT_POOL` |
| 势力排名 | 综合评分 = 声望×0.4 + 武力×0.3 + 领地×0.15 + 资金/100×0.15，含上升/稳定/下降趋势 | `getFactionRankings()` |
| 宗门加入 | 玩家可在对应地点"拜入"宗门，丐帮/魔教无条件可入，其他需到达山门 | `joinSect()` / `canJoinSect()` |
| 玩家贡献 | 完成日常任务后自动为所属宗门增加声望和资金 | `contributeToFaction()` |
| 个人日志 | 记录修行历程：宗门加入、晋升、任务完成、旅行、战斗等 | `addChronicleEntry()` / `getChronicle()` |
