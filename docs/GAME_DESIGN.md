## 一、游戏定位

「仙侠开放世界」× 「宝可梦式角色养成」

### 世界观核心
- **九霄龍脈 ：主角体内封印的禁忌皇权之力
- **故事起点**：前朝覆灭，幼年太子被国师墨綰青封印记忆隐居小村。十六年后追兵到来，主角逃往武当山，开启江湖之路
- **剧情类型**：
  - **不可重复剧情**：主线剧情（章节推进）、支线剧情（角色个人线）
  - **可重复剧情**：日常任务（砍柴、挑水等）、随机任务（江湖偶遇、突发事件）

## 二、修为境界体系

> 每个大境界分 **10 个小层**（如炼气一层~炼气十层）。
> 等级数值 `level` 从 0 开始：0=凡人，1=炼气一层，2=炼气二层……10=炼气十层，11=筑基一层……
>
> **🆕 0507 突破机制重构**：修为等级与宗门身份解耦，不再由剧情直接绑定。
> - **小层晋升**：积累修为自动晋升（与之前相同）
> - **大境界突破**：满层+经验满后，剧情解锁对应大境界（`realmBreakUnlocked`），玩家在属性面板点击「⚡ 突破境界」按钮主动突破
> - **宗门身份**（`discipleRank`）：外门→内门→真传→长老，由剧情推进独立解锁，不影响修为
> - 为沙盒模式预留：未来可通过宗门任务 + 突破丹替代剧情解锁

| 大境界 | level范围 | 小层 | 颜色 | 突破条件 |
|--------|-----------|------|------|----------|
| **凡人** | 0 | 0层 | — | — |
| **炼气** | 1~10 | 1~10层 | ⚪ 白色 | 入武当自动突破（无需解锁） |
| **筑基** | 11~20 | 1~10层 | 🟢 绿色 | 炼气十层满 + 经验满 + C3突破剧情解锁筑基 → 玩家点击突破 |
| **结丹** | 21~30 | 1~10层 | 🔵 蓝色 | 筑基十层满 + 经验满 + 剧情解锁 → 玩家点击突破 |
| **元婴** | 31~40 | 1~10层 | 🟣 紫色 | 结丹十层满 + 经验满 + 剧情解锁 → 玩家点击突破 |
| **化神** | 41~50 | 1~10层 | 🟡 金色 | 元婴十层满 + 经验满 + 剧情解锁 → 玩家点击突破 |
| **渡劫** | 51~60 | 1~10层 | 🔴 红色 | 化神十层满 + 经验满 + 剧情解锁/渡劫丹 → 玩家点击突破 |

### 突破机制详解

> 突破大境界需要同时满足三个条件，缺一不可：

```
✅ 条件1：当前等级为大境界第十层（满层，如炼气十层=10）
✅ 条件2：经验条已满（exp ≥ getExpForLevel(lv)）
✅ 条件3：该大境界已被剧情解锁（realmBreakUnlocked 包含目标境界ID）
```

> 三个条件全部满足时，属性面板的经验条下方出现 **「⚡ 突破境界」** 红色按钮，点击后：
> 1. 消耗满经验条（exp 归零）
> 2. level 跃升至下一境界第一层（如 10→11）
> 3. 按 `realmConfig.ts` 的 `calculateFinalStats()` 重算全部属性（含大境界断层增幅 + 主角天赋加成）

> **与旧版的区别**：
> - 旧版：剧情直接设置 `level`（如 `enter_chapter3` 设 level=11），修为与剧情强绑定
> - 新版：剧情仅解锁突破条件（`realmBreakUnlocked`），玩家自主决定何时突破，修为与剧情解耦

### 宗门身份体系

> 宗门身份（`discipleRank`）**独立于修为等级**，仅由剧情推进决定。身份影响可用的日常任务、可学习的技能等，但不直接决定修为。

| 身份 | 值 | 解锁剧情 | 说明 |
|------|-----|----------|------|
| 外门弟子 | `outer` | 入武当默认 | 可用外门日常任务（砍柴、挑水等） |
| 内门弟子 | `inner` | 第二章 ch2_xiasha（外门试炼考） | 砍柴/挑水不再可用，解锁内门技能 |
| 真传弟子 | `true` | 第三章 ch3_zhenchuan（晋升真传） | 解锁真传技能（太极拳、太极剑等） |
| 长老 | `elder` | 后续章节 | 预留 |

### 🆕 0508 宗门晋升系统（沙盒路径）

> 提供一条**独立于主线剧情**的宗门晋升路径：贡献值 + 试炼 → 晋升身份。

| 晋升 | 贡献值要求 | 试炼 | 说明 |

| 晋升方式 | 触发条件 | 写入字段 |

| 沙盒晋升 | 贡献值达标 + 完成试炼 | 同上 |

两条路径互不冲突，写入同一个字段。

## 五、战斗系统

### 架构：4v4 团队战

战斗从原来的 1v1 单挑重构为支持 **1v1~4v4 团队战**的架构：

- **我方单位**：主角（`player_main`）+ 最多 3 名队友（`ally_1`~`ally_3`）
- **敌方单位**：1~4 名敌人（`enemy_0`~`enemy_3`）
- **回合顺序**：交替穿插（1A-1B-2A-2B-3A-3B-4A-4B），双方交替行动
- **目标选择**：玩家点击敌方单位选择目标，再点击技能释放
- **状态效果**：按单位独立存储（`allyStatuses` / `enemyStatuses`），持久化到战斗结束
- **当前章节**：第一章教学战为 1v1，后续章节逐步引入队友

### 伤害公式
```
伤害 = max(1, ATK × powerMul - DEF × defPen) × [0.9,1.1] × (暴击?1.5:1)
```

## 七、沙盒模式 🆕

> 沙盒模式是主线剧情的**平行扩展**，不是替代。玩家可以选择推主线，也可以选择在沙盒中自由发展。两条路径最终交汇。
> 设计理念：太阁立志传的自由度 × 信长之野望的势力驱动 × 三国志13的势力线。

### 7.1 双模式设计

`gameMode` 字段控制当前模式。两种模式**共享同一个存档**、同一套修为/宗门身份字段：

| 维度 | 主线模式 | 沙盒模式 |
|------|---------|---------|
| 修为突破 | 剧情解锁 `realmBreakUnlocked` → 手动突破 | 同上，或服用突破丹替代剧情解锁 |
| 宗门身份 | 剧情设置 `discipleRank` | 贡献值 + 晋升试炼 → 平行晋升路径 |
| 技能获取 | 剧情 VN 授予 | 剧情 + 偷师（P5-1 待实装） |
| 核心循环 | 推剧情 → 日常练级 → 突破 → 推剧情 | 做任务 → 攒贡献 → 晋升 → 更高阶任务 |

> **内部连接性**：沙盒晋升和剧情晋升写入**同一个 `discipleRank` 字段**。如果先通过沙盒升到内门，主线 ch2_xiasha 晋升时检测到已是内门则自动跳过。切回主线时，修为、身份、NPC 状态、好感度全部保留——你可以用元婴期实力碾压本该艰难的筑基期剧情战斗。

### 7.2 贡献值与宗门晋升

贡献值是沙盒的核心驱动货币，与经验/金币并行：

| 来源 | 贡献值 | 经验 | 金币 |
|------|--------|------|------|
| 🪓 砍柴 | +2 | +20 | +5 |
| 💧 挑水 | +2 | +15 | +3 |
| 🧹 打扫大殿 | +3 | +18 | +4 |
| 📜 抄写道经 | +5 | +35 | +8 |
| 🌙 后山修炼 | +3 | +45 | 0 |
| ⚔️ 演武切磋 | +4 | +55 | 0 |
| 📋 宗门任务 | 5~30 | 30~150 | 10~80 |

沙盒晋升路径（仅依赖贡献值 + 试炼，与修为解耦）：

| 晋升 | 贡献值 | 试炼 |
|------|--------|------|
| 外门→内门 | 200 | 下山剿匪（vs 山贼精英） |
| 内门→真传 | 500 | 演武试剑（vs 陆沉舟） |
| 真传→长老 | 1000 | 传功授业（教学任务） |

属性面板显示贡献进度条 +「开始试炼」按钮。晋升后解锁新身份对应的地点权限和日常任务。

### 7.3 任务系统

左侧常驻任务栏，显示当前接取的任务。任务无期限，接受后一直悬挂：

- NPC 掌门/长老分配主命任务（剿匪、采集、护送等）
- 日常任务自动推进相关任务进度
- 每月评定可接取 1~2 个新任务
- 完成 → 贡献值 + 声望 + 奖励；可放弃（扣少量贡献值）

> **与日常的互联**：执行日常任务（砍柴/修炼）时自动检测并推进相关任务进度，无需额外操作。

### 7.4 势力倾向与外交

基于信长之野望的势力文化驱动 NPC 行为和势力关系。6 个现有势力各有倾向和文化标签：

| 势力 | 倾向 | 文化标签 |
|------|------|----------|
| 武当派 | `righteous` | taoist, sword, mountain, inner-peace |
| 少林寺 | `righteous` | buddhist, fist, temple, discipline |
| 峨眉派 | `righteous` | buddhist, sword, mountain, female |
| 丐帮 | `righteous` | beggar, palm, street, loyalty |
| 华山派 | `neutral` | sword, mountain, rivalry |
| 黑月教 | `chaotic` | moon, shadow, forbidden, power |

外交演算：倾向匹配（正道×正道友好加成）+ 文化相似度（共同标签数 × 10）→ 决定外交事件概率。友好度 > 60 时 70%友好事件，< 30 时 50%冲突。

> **NPC 行为联动**：正道 NPC 倾向修炼互助，邪道 NPC 倾向掠夺冲突。玩家行为也会影响势力关系（介入外交事件、送礼修好）。

### 7.5 世界演算引擎

借鉴三国志13的个人-势力线。每 3 次日常行动触发世界 tick：

- **势力资源**：6 门派各有资金 / 弟子 / 地盘 / 声望 / 稳定度 / 武力，随回合自然波动 ±2
- **世界事件**：10 种江湖事件（武林大会、匪患、商路、疫病、武学突破、魔教渗透等），10% 概率触发
- **势力排名**：综合分 = 声望×0.4 + 武力×0.3 + 地盘×0.15 + 资金/100×0.15，含上升/稳定/下降趋势
- **个人日志**：修行历程全记录——宗门加入、晋升、任务完成、旅行、战斗
- **宗门加入**：在对应地点拜入其他宗门（丐帮/黑月教无条件可入，其他需到达山门）

> 查看入口：营地左侧「🌏 江湖态势」Tab → `WorldPanel.ts`

### 7.6 NPC 生态

沙盒需要完整的 NPC 生态支撑自由玩法：

- **固定 NPC**：13 个剧情 NPC + 6 个门派掌门 + 6 个传功长老 + 9 个城市官员 = 34 人
- **随机 NPC 生成器**：`NPCGenerator.ts` → 门派中枢弟子 + 城市游荡者 + 京城官员。门派性别规则：少林全男、峨眉全女，其余 55:45
- **NPC 行为引擎**：每回合购买法器/学习技能/修炼（三选一）+ 35% 概率移动到相邻地点
- **「附近的人」**：营地右侧边栏显示当前地点 NPC 立绘卡片，点击查看完整属性。NPC 移动后实时更新

> NPC 数据全部持久化在 `PlayerState.npcDatabase` 中，随存档保存。

### 7.7 朝廷双轨制

沙盒提供"庙堂之路"——玩家在京城（开封）参与朝廷事务，积累影响力升品阶：

| 品阶 | 解锁行动 | 门槛 |
|------|---------|------|
| 秀才 | 整理卷宗 | 50 |
| 举人 | 审理案件 | 200 |
| 进士 | 巡查郡县 | 600 |
| 翰林 | 草拟奏章 | 1500 |
| 侍郎 | 六部议事 | 4000 |
| 尚书 | 统辖一部 | 8000 |
| 大学士 | 参议朝政 | 15000 |
| 宰相 | 总领百官 | 25000 |

双线选择：**文官线**（谋略+辩才）vs **武官线**（谋略+魅力）。D100 掷骰 + 修正值判定政务成败。影响力 = 朝廷的"修为"。

### 7.8 法器商店与突破丹

- **法器商店**：宗门商店（品质与门派声望挂钩）和城市商店，按境界分组浏览购买
- **突破丹**：沙盒玩家可服丹替代剧情解锁大境界突破。通过修炼、商店购买、任务奖励获得

> 突破丹让沙盒玩家的修为突破**完全不依赖主线剧情**。你可以在第一章练到元婴，只要攒够突破丹。
