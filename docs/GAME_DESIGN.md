## 一、游戏定位

「仙侠开放世界」× 「宝可梦式角色养成」

### 世界观核心
- **九霄龍脈 ：主角体内封印的禁忌皇权之力
- **故事起点**：前朝覆灭，幼年太子被国师墨綰青封印记忆隐居小村。十六年后追兵到来，主角逃往武当山，开启江湖之路
- **剧情类型**：
  - **不可重复剧情**：主线剧情（章节推进）、支线剧情（角色个人线）
  - **可重复剧情**：日常任务（砍柴、挑水等）、随机任务（江湖偶遇、突发事件）

## 二、修为境界体系

> 每个大境界分 **10 个小层**（如炼气一层~炼气十层）。
> 等级数值 `level` 从 0 开始：0=凡人，1=炼气一层，2=炼气二层……10=炼气十层，11=筑基一层……
>
> **🆕 0507 突破机制重构**：修为等级与宗门身份解耦，不再由剧情直接绑定。
> - **小层晋升**：积累修为自动晋升（与之前相同）
> - **大境界突破**：满层+经验满后，剧情解锁对应大境界（`realmBreakUnlocked`），玩家在属性面板点击「⚡ 突破境界」按钮主动突破
> - **宗门身份**（`discipleRank`）：外门→内门→真传→长老，由剧情推进独立解锁，不影响修为
> - 为沙盒模式预留：未来可通过宗门任务 + 突破丹替代剧情解锁

| 大境界 | level范围 | 小层 | 颜色 | 突破条件 |
|--------|-----------|------|------|----------|
| **凡人** | 0 | 0层 | — | — |
| **炼气** | 1~10 | 1~10层 | ⚪ 白色 | 入武当自动突破（无需解锁） |
| **筑基** | 11~20 | 1~10层 | 🟢 绿色 | 炼气十层满 + 经验满 + C3突破剧情解锁筑基 → 玩家点击突破 |
| **结丹** | 21~30 | 1~10层 | 🔵 蓝色 | 筑基十层满 + 经验满 + 剧情解锁 → 玩家点击突破 |
| **元婴** | 31~40 | 1~10层 | 🟣 紫色 | 结丹十层满 + 经验满 + 剧情解锁 → 玩家点击突破 |
| **化神** | 41~50 | 1~10层 | 🟡 金色 | 元婴十层满 + 经验满 + 剧情解锁 → 玩家点击突破 |
| **渡劫** | 51~60 | 1~10层 | 🔴 红色 | 化神十层满 + 经验满 + 剧情解锁/渡劫丹 → 玩家点击突破 |

### 突破机制详解

> 突破大境界需要同时满足三个条件，缺一不可：

```
✅ 条件1：当前等级为大境界第十层（满层，如炼气十层=10）
✅ 条件2：经验条已满（exp ≥ getExpForLevel(lv)）
✅ 条件3：该大境界已被剧情解锁（realmBreakUnlocked 包含目标境界ID）
```

> 三个条件全部满足时，属性面板的经验条下方出现 **「⚡ 突破境界」** 红色按钮，点击后：
> 1. 消耗满经验条（exp 归零）
> 2. level 跃升至下一境界第一层（如 10→11）
> 3. 按 `realmConfig.ts` 的 `calculateFinalStats()` 重算全部属性（含大境界断层增幅 + 主角天赋加成）

> **与旧版的区别**：
> - 旧版：剧情直接设置 `level`（如 `enter_chapter3` 设 level=11），修为与剧情强绑定
> - 新版：剧情仅解锁突破条件（`realmBreakUnlocked`），玩家自主决定何时突破，修为与剧情解耦

### 宗门身份体系

> 宗门身份（`discipleRank`）**独立于修为等级**，仅由剧情推进决定。身份影响可用的日常任务、可学习的技能等，但不直接决定修为。

| 身份 | 值 | 解锁剧情 | 说明 |
|------|-----|----------|------|
| 外门弟子 | `outer` | 入武当默认 | 可用外门日常任务（砍柴、挑水等） |
| 内门弟子 | `inner` | 第二章 ch2_xiasha（外门试炼考） | 砍柴/挑水不再可用，解锁内门技能 |
| 真传弟子 | `true` | 第三章 ch3_zhenchuan（晋升真传） | 解锁真传技能（太极拳、太极剑等） |
| 长老 | `elder` | 后续章节 | 预留 |

### 🆕 0508 宗门晋升系统（沙盒路径）

> 提供一条**独立于主线剧情**的宗门晋升路径：贡献值 + 试炼 → 晋升身份。

## 五、战斗系统

### 架构：4v4 团队战

战斗从原来的 1v1 单挑重构为支持 **1v1~4v4 团队战**的架构：

- **我方单位**：主角（`player_main`）+ 最多 3 名队友（`ally_1`~`ally_3`）
- **敌方单位**：1~4 名敌人（`enemy_0`~`enemy_3`）
- **回合顺序**：交替穿插（1A-1B-2A-2B-3A-3B-4A-4B），双方交替行动
- **目标选择**：玩家点击敌方单位选择目标，再点击技能释放
- **状态效果**：按单位独立存储（`allyStatuses` / `enemyStatuses`），持久化到战斗结束
- **当前章节**：第一章教学战为 1v1，后续章节逐步引入队友

### 伤害公式
```
伤害 = max(1, ATK × powerMul - DEF × defPen) × [0.9,1.1] × (暴击?1.5:1)
```

## 七、沙盒模式（自由模式）🆕

> **⚠️ 核心设计理念（2026-05-09 修正确认）**：
> **沙盒模式 = 自由模式 = 游戏本体/地基**。它不是主线剧情的"平行扩展"，而是整个游戏的底层框架。
> 剧情模式是叠加在沙盒地基上的一层"作弊器"——剧情节点直接修改玩家数值（类似控制台指令），让玩家快速跳过养成环节体验故事。
>
> **类比**：沙盒是"我的世界"的生存模式（自然成长），剧情是"我的世界"的创造模式切一段故事过场（直接改数据）。
>
> 两者共享**同一套数值系统、同一套 UI、同一个存档**。剧情模式不会"切换到另一个模式"，只是在沙盒底子上附加了一段自动推进的故事演出。
>
> 设计理念：太阁立志传的自由度 × 信长之野望的势力驱动 × 三国志13的势力线。

### 7.1 沙盒与剧情的关系

**沙盒是地基，剧情是层叠**。不存在两个独立的"模式"需要切换：

```
┌─────────────────────────────────┐
│        主线剧情（作弊层）         │  ← 剧情节点直接修改 PlayerState
│   ch2_xiasha → discipleRank='inner' │     （跳过养成环节，快速提升）
│   ch3_break → realmBreakUnlocked   │
├─────────────────────────────────┤
│        沙盒系统（游戏本体）       │  ← 所有底层机制：修为、宗门、NPC、
│   日常任务 → 贡献值 → 晋升试炼    │     战斗、法宝、世界演算……
│   突破机制 → NPC 行为 → 朝廷     │
└─────────────────────────────────┘
```

**关键规则**：
- 剧情晋升和沙盒晋升写入**同一个 `discipleRank` 字段**。剧情相当于调用了"作弊指令"直接设置身份。
- 沙盒路径才是"真实的成长路径"：做日常 → 攒贡献 → 完成试炼 → 晋升。
- 如果先通过沙盒升到内门，主线推进到对应节点时检测到已是内门则自动跳过。
- 切回主线时，修为、身份、NPC 状态、好感度全部保留——你可以用元婴期实力碾压筑基期剧情战斗。
- **开发优先级**：先打磨沙盒底层，再在其上开发剧情。确保沙盒本身是一个可玩的完整游戏。

| 维度 | 沙盒路径（真实成长） | 剧情路径（作弊直达） |
|------|---------------------|---------------------|
| 修为突破 | 修炼 + 突破丹（沙盒自主） | 剧情解锁 `realmBreakUnlocked`（跳过修炼） |
| 宗门身份 | 贡献值 + 晋升试炼（自然积累） | 剧情直接设置 `discipleRank`（跳过试炼） |
| 技能获取 | 剧情 VN + 偷师 + 拜师 | 剧情 VN 授予 |
| 核心循环 | 做任务 → 攒贡献 → 晋升 → 更高阶任务 | 推剧情 → 得数值 → 推下一段剧情 |

| 等级 | 概率 | 天赋数 | 说明 |
|------|------|--------|------|
| 绝世 | 3% | 3 | 万里挑一，极大改变战斗力 |
| 上等 | 11% | 6 | 明显优势，门派重点关注 |
| 中等 | 45% | 15 | 普通天赋，大多数 NPC 的主力 |
| 下等 | 28% | 9 | 微弱势或无关紧要 |
| 诅咒 | 11% | 3 | 负面天赋，命运多舛 |

| 天赋ID | 名称 | 等级 | 效果 |
|--------|------|------|------|

| `dragon_vein` | 龙脉觉醒 | 绝世 | 全属性+20%，暴击+10% |

### 7.9 天骄系统 🆕 0509

> 借鉴鬼谷八荒的天骄机制：**0.5% 的随机 NPC** 被标记为"天骄"——强制拥有 3 个绝世/上等天赋，修行速度 ×1.5，全属性 +20%。

#### 天骄规则

| 维度 | 数值 |
|------|------|
| 天骄比例 | 0.5%（每 200 个 NPC 约出 1 个） |
| 天赋保障 | 强制至少 2 绝世 + 1 上等（或 3 绝世） |
| 修行速度 | ×1.5（叠加天赋后可能更高） |
| 属性加成 | 全属性（HP/MP/ATK/DEF/AGI/暴击）+20% |
| 特殊标记 | NPC 面板显示「🌟 天骄」标识，名字金色高亮 |
| 全局数量 | 约 3~5 个（500~800 NPC 池） |
| 出现范围 | 任何宗门、任何层级（旁门也可能出天骄） |

#### 天骄的江湖影响

- 天骄 NPC 的修为成长速度远超同门，可能从外门快速晋升到真传甚至长老
- 天骄 NPC 更可能触发特殊世界事件（突破、奇遇、被挑战）
- 玩家可以在「附近的人」或人物关系中识别天骄（金色名字 + 🌟 标记）
- 天骄可能成为玩家的强力队友或宿命对手
